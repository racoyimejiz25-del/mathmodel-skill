# CUMCM / 高教社杯 Figure Visual Quality Gate

本模板实现 `modules/04_figure_evidence.md` 的 Competition Visual Quality Gate，不拥有独立 Figure Authority，也不要求安装任何外部作图库。

## 核心定位：高教社杯是质量标尺，不是唯一参考源

本 Gate 中“与近几年高教社杯优秀论文水平相近”的含义是：**最终 Figure 的整体视觉完成度、清晰度、版面成熟度和论文融合度至少应达到相近档次**。它是质量目标，不是模仿任务，也不是唯一的选图/设计参考来源。

实际选图与视觉设计仍采用多源参考：

- 当前问题的 Core conclusion、Evidence Structure 与 accepted workbook 始终优先；
- 同领域同行评审论文与综述用于学习科学证据如何可视化；
- 高质量会议论文、预印本、官方技术报告、标准和机构报告可用于补充领域视觉惯例；
- 近几年高教社杯/全国大学生数学建模竞赛公开展示优秀论文用于校准竞赛论文的**整体视觉完成度与评阅读图体验**；
- 必要时可参考成熟科研可视化方法的通用设计原则，但不得为了“像某种风格”牺牲当前证据表达。

因此，不允许出现以下两种误解：

1. **完全照着高教社杯论文画**：禁止复制、描摹、换色复刻具体 Figure、palette、panel 排版或视觉皮肤；
2. **只看高教社杯论文选图**：高教社杯不是唯一视觉资料库，专业领域论文和权威技术资料在图型与证据结构选择上通常更重要。

## 官方质量锚点

全国大学生数学建模竞赛官网的“历年竞赛结果”将“历年论文展示”指向教育部中国大学生在线数学建模论文展示页面。CUMCM 正式论文 Figure 在联网条件允许时，可查看近几年组委会公开展示优秀论文，用来判断自己的图在竞赛论文语境下是否已经达到相近的整体成熟度。

稳定入口：

- 全国大学生数学建模竞赛官网历年竞赛结果：`https://www.mcm.edu.cn/html_cn/block/018500ec1a6bd8c7e9997133def2b590.html`
- 中国大学生在线历年数学建模论文展示：`https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml`

这些入口只承担**竞赛视觉质量校准**。不得从展示论文复制图形设计，也不得从展示图逆推任何数值。

## 相近水平的成熟度目标

最终 Figure 至少应避免明显低于近年公开展示优秀论文的整体视觉完成度。重点检查：

| 维度 | PASS 要求 | 常见 FAIL |
|---|---|---|
| 信息主次 | 第一眼能识别核心对象、主要比较或临界区域 | 所有元素同权重、同饱和度 |
| 配色协调 | 色彩克制且有语义，同类对象全文一致 | 默认随机色序、彩虹色、过度鲜艳 |
| 字体与字号 | 按论文实际插入尺寸仍能读清坐标、单位、legend | MATLAB 窗口里清楚，插 Word 后变小 |
| 轴与网格 | 轴线清楚但不厚重；网格必要才启用且弱化 | 粗黑边框、密集深网格 |
| 留白与画布 | plot area、legend、colorbar、annotation 有稳定空间 | 文字挤压、裁切、大片无意义空白 |
| 图例策略 | 不遮挡证据，跨 panel 语义统一 | legend 压在关键数据上、每 panel 重复大图例 |
| 证据完整性 | 阈值、CI、边界、推荐点、样本分布存在时得到表达 | 为了好看把关键证据删成几根柱/线 |
| 图题关系 | caption 承担论文图名，图内只保留读图需要的标签 | 图内重复大标题、subtitle 堆叠 |
| 风格一致性 | 同篇论文颜色、字体、线宽、marker 语法基本稳定 | 每张图像来自不同模板 |
| 适度美感 | 干净、平衡、有焦点，视觉密度与科学信息匹配 | 霓虹、阴影、发光、装饰性 3D、花哨背景 |

## Benchmark Procedure

联网且当前任务是 CUMCM 正式 Figure 时：

1. **先按 Evidence Structure 进行多源选图**：优先检索同领域论文、综述、官方技术资料，确定同类证据通常采用什么科学视觉结构；
2. 再查看近年高教社杯公开展示优秀论文，校准竞赛论文语境下的版面秩序、信息密度、标注密度、配色克制程度、panel 组织和最终完成度；
3. 若领域论文的科学表达明显优于竞赛论文常见做法，可吸收其更合适的结构，但最终成图仍需达到成熟竞赛论文应有的可读性和整体美感；
4. 当相关视觉模式已经趋于稳定即可停止，不设置固定篇数；
5. 只提取可迁移原则，不复制任何具体图形皮肤；
6. 回到当前 accepted workbook 和 Figure Contract 完成独立设计。

高教社杯展示论文与其他外部资料都只是参考；**最终 Figure 必须是针对当前问题重新设计的独立作品**。

若无法联网，不阻塞绘图；直接按 Module 04 的稳定审美规则执行。

## Final-size 审美复核

所有准备进入正文的 Figure 都必须在预计插入宽度下复核，而不是只在 MATLAB / Python 大图窗里判断：

- 文字是否仍清楚；
- 主次是否仍明显；
- 颜色在缩小后是否仍可区分；
- legend / colorbar 是否挤压数据区；
- marker、线型和误差带是否仍可辨；
- a/b/c/d panel label 是否统一；
- 图与 caption 连续阅读时是否自然。

若缩小后美感和证据层级明显下降，优先重新布局、拆图、减少冗余标注或调整视觉权重，不要简单继续缩小字体。

## 与正文准入的边界

**好看不能让一张低价值图进入正文。** Competition Visual Quality Gate 只评估“值得存在的 Figure 是否已经达到成熟、接近优秀竞赛论文档次的视觉完成度”；是否值得进入正文仍由 Main-text Admission Gate 决定。
